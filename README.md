# Iskomeet -- A Filipino college dating platform

- This is created as my Application Development (AppDev) course in my BS Computer Science program. 

## WHAT IS THIS

- Iskomeet is a web-based dating platform. Created as a web app to make it widely accessible across different mobile operating systems, expediting its release while meeting the multi-OS requirements.

## FEATURES
    
- Messaging, Liking
- Swipe-left (Pass), Swipe-right (Like), Swipe-up (Super Like)
